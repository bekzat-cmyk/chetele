# События

Вход в админ-кабинет задаётся в `api/config.php`. Паролей по умолчанию нет: пока `admin_login` и `admin_password` (от 12 символов) не заданы, админ-API закрыт.

```php
'admin_login' => 'ваш-логин',
'admin_password' => 'длинный-случайный-пароль',
```

После публикации сайта откройте `/admin.html`, войдите под этими данными и создайте событие. Таблицы `events` и `event_participants` API создаёт автоматически; при ручной миграции используйте `database/migrate_events.sql`.

Первая версия поддерживает события по салаватам. После вступления пользователя его ежедневные отметки «Салават» автоматически учитываются в личном, общем и рейтинговом прогрессе события.
