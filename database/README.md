# База данных «Ниет»

Для PHP-хостинга:

1. В phpMyAdmin выберите базу данных.
2. При первой установке импортируйте `schema.sql`.
3. Если база уже используется, не импортируйте всю схему повторно: API самостоятельно создаст `push_subscriptions`, а при необходимости можно отдельно выполнить `migrate_push.sql`.
4. Параметры MySQL и VAPID-ключи хранятся только в `api/config.php`, а не в браузерном коде.

Инструкцию по ежедневным серверным уведомлениям смотрите в `PUSH_SETUP.md` в корне проекта.
