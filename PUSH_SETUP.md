# Серверные уведомления Web Push

Эта версия уже содержит VAPID-ключи и серверную отправку. Не публикуйте файл `api/config.php`: он защищён `api/.htaccess` и должен оставаться только на сервере.

## Что загрузить на хостинг

Загрузите с сохранением структуры папок:

- `index.html` и `sw.js`;
- папки `api`, `cron` и `assets` целиком;
- `.htaccess` из корня проекта.

После первого обращения к API таблица `push_subscriptions` создастся автоматически. Если на MySQL-пользователя не выданы права `CREATE`, импортируйте в phpMyAdmin файл `database/migrate_push.sql`.

## Что включить на хостинге

1. Используйте HTTPS для домена.
2. В панели хостинга выберите PHP **8.1 или 8.2** для сайта.
3. Убедитесь, что доступны расширения `pdo_mysql`, `openssl` и `curl`.
4. В разделе **Планировщик / Cron-задачи** добавьте задачу раз в минуту. Команда имеет вид:

   ```
   /usr/bin/php /полный/путь/к/сайту/cron/send-reminders.php >/dev/null 2>&1
   ```

   Полный путь обычно виден в файловом менеджере панели. Период — `каждую минуту` или выражение `* * * * *`.

Если раздела Cron нет, отправьте поддержке хостинга сообщение:

> Нужна Cron-задача раз в минуту для PHP-файла `cron/send-reminders.php` и включённые расширения PHP `curl`, `openssl`, `pdo_mysql`.

## Проверка

1. На iPhone добавьте сайт на экран «Домой», затем откройте именно установленное приложение. На Android можно открыть установленную версию в Chrome.
2. В настройках приложения нажмите «Включить», разрешите уведомления, выберите время.
3. Сразу должен прийти тест. В phpMyAdmin появится строка в `push_subscriptions`.
4. После настройки Cron уведомления будут приходить каждый день в 12:00, 16:30 и 20:00 по времени телефона, даже если приложение закрыто.

Сервер сохраняет часовой пояс телефона. Недействительные подписки (например, после удаления приложения) сервер отключает автоматически.
